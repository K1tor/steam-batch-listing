# Steam 库存批量上架助手(浏览器插件)

在 Steam 库存页多选物品,一键批量在 Steam 市场上架出售。Chrome / Edge(MV3)可用。

## 功能

- 库存页注入悬浮面板:多选模式(点选物品)、全选本页、清空选择
- 两种定价策略:
  - **市场最低价(可偏移)**:自动查询每种物品的当前最低挂单价,可设置"低于最低价 N%"来压价抢排名
  - **固定价格**:所有选中物品按同一价格上架(按钱包币种填写)
- 逐件上架,间隔可调(默认 800ms,最低 300ms),遇到 429/502 限流自动等待重试
- 两次点击确认防误触;可随时停止;实时日志与进度条
- 自动跳过不可出售(marketable=0)的物品;已售物品在页面上置灰标记
- 设置自动保存

## 安装

1. 打开 Chrome / Edge,地址栏输入 `chrome://extensions`(Edge 为 `edge://extensions`)
2. 打开右上角(Edge 为左侧)的 **开发者模式**
3. 点击 **加载已解压的扩展程序**,选择本文件夹 `steam-batch-listing`
4. 打开自己的库存页:https://steamcommunity.com/my/inventory/ ,右下角出现「📦 批量上架」面板即安装成功

## 使用

1. 点击 **开启多选**,然后直接点选库存物品(再点一次取消);或切页后用 **全选本页** 累加
2. 选择定价策略:
   - 市场最低价:偏移填 `0` 同价出售,填 `2` 表示低于最低价 2%(结果不低于 0.03)
   - 固定价格:输入价格,如 `12.50`(钱包币种)
3. 点击 **开始上架** → 6 秒内 **再点一次确认** 即开始;面板显示进度和每件结果
4. 出错或想中止点 **停止**,当前这一件完成后退出

## 注意事项

- 需要在 steamcommunity.com **已登录**,且账号 Steam 令牌启用满 15 天才能上架市场
- 每件物品都是单独调用 Steam 的出售接口(`POST /market/sellitem/`),和手动点"出售"完全等价;请勿把间隔调得过低刷单
- 若账号开启了「需要手机确认市场交易」,上架后需到 **Steam 手机 App** 确认挂单
- 堆叠类物品(如宝石、钥匙)每次上架 1 个;CS2 饰品按默认状态(含贴纸)上架
- 间隔过小会触发 Steam 限流(HTTP 429),插件会自动等待 5 秒重试;建议保持默认 800ms
- 本工具只是把手动操作自动化,请在自己账号上合理使用,风险自负

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示未获取到 sessionid | 重新登录 Steam 后刷新页面;若刚更新过插件,先刷新扩展页 |
| 未检测到库存物品 | 确认打开的是库存页(`/inventory`);若 Steam 改版,更新 `content.js` 里的 `.item` 选择器 |
| 大量 429 限流 | 把间隔调大到 1500–3000ms |
| 价格查询失败"市场暂无挂单" | 该物品当前无人挂单,会自动跳过 |

## 文件结构

```
├── manifest.json    # MV3 清单
├── background.js    # Service Worker:读取会话 cookie
├── content.js       # 核心逻辑:面板 UI + 选择 + 批量上架
├── content.css      # 页面内物品选中/已售标记样式
└── icons/           # 插件图标
```
